# لوحة تحكم الخزينة — دليل الإعداد الكامل

## 📊 نظرة عامة

لوحة تحكم ويب احترافية لعرض تقرير حركة الخزينة اليومي. تتميز بـ:

- **تحديث تلقائي**: بمجرد حفظ ملف الإكسيل، يتم استخراج البيانات ونشرها تلقائياً
- **متاحة 24/7**: عن طريق GitHub Pages — تعمل حتى لو كان جهازك مطفأ
- **مراقب كل 10 ثوانٍ**: يراقب ملف الإكسيل بدقة وينشر التغييرات فوراً
- **تصميم Apple نظيف**: بخط Tajawal العربي الواضح، وألوان محايدة أنيقة
- **عرض كامل للبيانات**: الأرصدة، الحركات الواردة والمنصرفة، التحويلات، المشروعات، والرسم البياني

---

## 🚀 خطوات الإعداد (مرة واحدة فقط)

### المتطلبات الأساسية

1. **Python 3** — حمّله من https://python.org
2. **Git** — حمّله من https://git-scm.com
3. **حساب GitHub** — سجّل من https://github.com

### الخطوة 1: تثبيت المكتبات

```powershell
pip install openpyxl
```

### الخطوة 2: إعداد GitHub

1. أنشئ مستودعاً جديداً على GitHub: https://github.com/new
2. افتح PowerShell في مجلد `DELIVERY`:

```powershell
cd DELIVERY
git init
git checkout -b main
git add .
git commit -m "النسخة الأولى من لوحة التحكم"
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```

3. فعّل GitHub Pages:
   - اذهب إلى إعدادات المستودع > Pages
   - Source: `Deploy from branch`
   - Branch: `main` > `/ (root)`
   - Save

4. لوحة التحكم ستكون متاحة على:
   ```
   https://USERNAME.github.io/REPO-NAME/
   ```

### الخطوة 3: تشغيل المراقب التلقائي

#### الطريقة أ: تشغيل يدوي (للتجربة)

```powershell
cd scripts
powershell -ExecutionPolicy Bypass -File watch_and_sync.ps1
```

#### الطريقة ب: مهمة مجدولة في ويندوز (يفضّل)

شغّل PowerShell كـ **Administrator**:

```powershell
cd scripts
.\setup.ps1
```

هذا سينشئ مهمة مجدولة تبدأ تلقائياً مع تشغيل الجهاز.

## 📁 هيكل الملفات

```
DELIVERY/
├── index.html          ← لوحة التحكم (افتحها في المتصفح)
├── data.json           ← البيانات المستخرجة من الإكسيل
│
scripts/
├── extract_data.py     ← يستخرج البيانات من الإكسيل إلى JSON
├── watch_and_sync.ps1  ← المراقب التلقائي (PowerShell)
├── watch_and_sync.py   ← المراقب التلقائي (Python)
└── setup.ps1           ← سكريبت الإعداد الشامل
```

## 🔄 آلية العمل

```
ملف الإكسيل (D:\)  ←  تحفظ التغييرات
        │
        ▼  (كل 10 ثوانٍ)
   المراقب يكتشف التغيير
        │
        ▼
 extract_data.py  ←  يستخرج البيانات
        │
        ▼
   data.json  ←  يُحدّث
        │
        ▼
   git push  ←  يُرفع إلى GitHub
        │
        ▼
 GitHub Pages  ←  المتصفح يظهر آخر تحديث
```

**هام**: ملف `index.html` يحمل البيانات من `data.json` تلقائياً، ويُحدّث نفسه كل 30 ثانية. كما يحتوي على نسخة احتياطية من البيانات مضمّنة داخله في حال تعذّر تحميل JSON.

-IntervalSeconds 10
